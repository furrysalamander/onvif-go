## Risk register

- **R1**: Events service materially more complex than other Phase-1 services
  (full WS-Notification). Mitigation: M6 isolated; can split Events into a
  Phase 1.5 so M3/M4/M5/M7 ship first if M6 slips.
- **R2**: OASIS/W3C support schemas import remote URLs (e.g. ws-addr.xsd).
  Mitigation: catalog resolves them locally, never fetched at runtime.
- **R3**: ONVIF capabilities XML often uses `xs:any` blobs. Mitigation: typed
  extension hooks with per-service unmarshal helpers for known shapes.
- **R4**: WS-Security digest algorithm has historically been misimplemented
  across ONVIF libs. Mitigation: explicit test vectors copied from the spec.
